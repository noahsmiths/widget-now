# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People who want a quick, personal glance at information from public websites without repeatedly visiting each page.

## Product Purpose

Widget Now turns a public webpage into a live, editable widget. Success means a user can create a useful glanceable view, save it to a private library, and rely on refreshed source data.

## Positioning

AI extracts data from a webpage and proposes widget designs, while the user retains control over layout and presentation. Saved widgets stay connected to their source for later refreshes.

## Operating Context

Users submit a public URL with optional instructions, choose a generated design, edit it in a web-based canvas, and save it. They can inspect extracted fields, refresh a source, and optionally set an email watch for a field condition.

## Capabilities and Constraints

- The current product is a React web app with Convex-backed authentication, generation, storage, and refresh.
- Sources are public HTTP(S) webpages. The current app does not access logged-in pages or provide native iOS widgets.
- Widget definitions are declarative data; the editor supports text, data, icons, shapes, sizing, positioning, and user-selected widget themes.
- Saved widgets and sources are private to their owners.

## Brand Commitments

- The product name is Widget Now.
- The requested app palette is black primary, light-grey secondary, blue accent, and pure-white background and theme.

## Evidence on Hand

The existing implementation and [README.md](README.md) document the current capabilities. No customer testimonials or performance claims are established in the repository.

## Product Principles

- Make important website information easy to scan at a glance.
- Keep source data current without silently changing a user's design.
- Give users control over presentation while preserving a reliable connection to extracted fields.
- Keep saved data and widgets private to their owners.
